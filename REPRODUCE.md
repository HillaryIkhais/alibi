# Reproduce Alibi from a clean clone

Every number quoted in the README is regenerated by one of the commands below. If a command does not
produce the stated output, the claim is false — trust the command, not the prose.

## Requirements
- Node.js 18+ (BigInt, `node:` built-ins)
- Docker + Docker Compose (only for the optional live regtest lab)

## 1. Policy conformance — 12/12 (no credentials, no Docker)

```bash
node engine/bin/adversarial-test.js
```

Expected tail:
```
TEST RESULTS: 12 passed, 0 failed
VENDOR POLICY ENFORCEMENT: VERIFIED
```
Also writes `evidence/adversarial-results.json` with a `checksum_sha256`. Covers: 20% and 5.01%
rejected, 5% boundary accepted, unauthorized marketplace/payee rejected, budget exhaustion,
sequential reservation reduction, exact-fit acceptance, duplicate hash rejected.

## 2. Mutation proof — 4/4 guards load-bearing

```bash
node engine/bin/mutation-test.js
```

Expected tail:
```
Mutation results: 4/4 guards confirmed load-bearing
Byte-identical restore: YES
```
Writes `evidence/mutation-results.json`. Each guard is disabled in a throwaway copy; the correlated
test must FAIL. The authoritative `adversarial-test.js` is restored byte-for-byte (SHA-256 recorded
before and after).

## 2b. Atomic budget under concurrency — 5 checks

```bash
node engine/bin/concurrency-test.js
```

Expected: `5/5 passed`, `ATOMIC BUDGET RESERVATION: VERIFIED (single-process)`. Eight interleaved
async arrivals against a 9-unit budget yield exactly three approvals (committed=9), no over-commit,
and no double reserve. Scope is single-process atomicity only — not distributed/multi-root.

## 3. HARBOR exit/recovery pipeline — 34 checks

```bash
cd engine
node test/run-pipeline.mjs
cd ..
```

Expected: `ALL PIPELINE CHECKS PASSED`, exit 0. Must run with cwd `engine/` (fixtures are resolved
relative to it). Uses fixtures + temp dir; no live node.

## 4. Channel-backup auditor — 10 checks

```bash
cd auditor
node test/run-offline.mjs
cd ..
```

Expected: `ALL OFFLINE CHECKS PASSED`, exit 0. Uses an in-process mock LND REST server.

## 5. Cancellation / recovery simulation

```bash
node engine/bin/commission-flow-simulator.js
```

Expected: `FLOW COMPLETE`, exit 0, all five cancellation invariants printed as holding. SIM mode;
no real funds.

## 6. Refresh the frozen manifest

```bash
node engine/bin/evidence-manifest.js
```

Writes `evidence/manifest.json`: SHA-256 of every proof artifact plus a manifest self-checksum.
This is how a judge confirms the committed bytes are the bytes that were run.

The verifier fails closed: exit 2 on missing credentials, exit 1 on any failed check, exit 0 only
when all 18 pass. The preimage is SHA-256-checked in memory and redacted before the bundle is written.

## Credential hygiene
Credentials are never committed. `.gitignore` blocks `*.macaroon`, `*.seed`, `*.key`, `*.cert`,
`data/*.pass`, and `*.log`. `evidence/` is intentionally committed so proof artifacts are visible.
See `evidence/runs/2026-11-17-offline/credential-scan.txt` for the history-wide scan.
